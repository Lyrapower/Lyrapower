`index.json` 是这张表的机器可读版。

## 字段

每个文件是 `{book, book_en, english_translation, sections: [...]}`，`sections` 里每一项：

- `n` 篇序；`title` 篇名；`zh` 原文，按段落分成字符串数组
- `en` 英译段落（只有道德经、孙子、庄子有）；`title_en` 英文篇名
- `subtitle` 道德经的章名（如「体道」）；`group` 分组（如 素问 / 灵枢、内篇 / 外篇、上经 / 下经）
- `lost_chapter` 黄帝内经的遗篇标记；`juan` 史记卷次；`note` 选篇说明
- 周易：`name` 卦名，`lines` 六爻（自下而上，1 为阳、0 为阴），`lower` / `upper` 下卦、上卦

## 来源和许可

- 底本：汉籍リポジトリ（Kanripo）对四部丛刊、四库全书的逐字录入。
- 标点：取通行标点本，和底本逐字对齐；两者不一致的地方以底本为准。
- 英译：Legge、Giles 的公版译本（Standard Ebooks 本）。
- 原著和这些英译都已进入公有领域。这里的整理与对齐工作以 [CC0](https://creativecommons.org/publicdomain/zero/1.0/) 放弃权利，不用署名；愿意的话，注明出处和链接就好。
